# Pckup Design System Migration Playbook

Static GitHub Pages guide for migrating the mature `senpex/pckup-web-app` frontend onto a scalable, governed design-system architecture.

## Public route

`/pckup-design-migration-playbook/`

## Contents

- Migration controller prompt used at the start of every agent session.
- Seventeen ordered phases with exact copy-ready prompts.
- Preconditions, required artifacts, exit gates, risks, and repeatability for each phase.
- Local-only prompt settings for repository, branch, Figma URL, family, surface, and run ID.
- Browser-local progress tracking and Markdown prompt export.

## Security

The site contains no credentials or application data. Prompt settings use browser `localStorage` and are not transmitted by the static site. Do not paste API keys, personal access tokens, service-account JSON, passwords, session cookies, or private environment values.
