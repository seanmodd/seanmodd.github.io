This is a migration of a live, heavily governed product—not a redesign sprint.

The sequence deliberately separates discovery, evidence, architecture, mechanical decomposition, canonicalization, Figma reconciliation, adoption, deletion, and governance. Skipping ahead will formalize the current chaos instead of fixing it.
