The missing middle between tokens and product UI

Move Pckup into a scalable design paradigm without replacing the product.

This guide assumes the repository is large, valuable, tested, deployed, and full of load-bearing behavior. It turns scattered React components and global CSS into a canonical code system, reconciled Figma libraries, accurate Code Connect mappings, bounded surface migrations, and permanent enforcement.

This is not a Figma export project.

The dependency chain is census → runtime evidence → taxonomy → architecture → owned CSS → canonical components → shells and surfaces → Figma and Code Connect → enforcement and retirement. Claude Design is optional and is not on the critical path.
