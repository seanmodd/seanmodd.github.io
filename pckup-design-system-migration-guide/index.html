Production-safe migration playbook

Move a mature codebase into a scalable design system without rewriting it.

This guide is built for the real Pckup repository: strong tokens, deep business logic, multiple product surfaces, thousands of global CSS rules, partial Figma coverage, and a need for a permanent design workflow that both humans and AI agents can follow.

Start Phase 00
!
This is not a Figma export project.

The critical path is codebase census → component consolidation → target architecture → Figma canon → Code Connect → surface migration → enforcement. Claude Design is optional and deliberately outside the dependency chain.

Operating model

A controlled migration state machine

How to use this guide

Copy, run, verify, then unlock the next phase

01

Open a fresh agent session

Run Claude Code or Codex against the current repository. Use the highest reasoning/effort available and connect Figma MCP only for the Figma phase.

02

Copy the complete phase prompt

Every Copy button combines the global operating contract with the exact phase instructions, so each session is self-contained.

03

Respect the exit gate

Do not click Complete because code was written. Mark a phase complete only after its artifacts, reviews, merge, deployment, and verification are true.

04

Use the unit loop

Large phases require many small PRs. Use the reusable Next Migration Unit prompt after every merged unit instead of asking an agent to refactor the whole frontend.
