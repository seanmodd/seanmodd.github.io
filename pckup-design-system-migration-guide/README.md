# Pckup Design System Migration Command Center

Static public workflow guide for the controlled Pckup Design System v2 migration.

The site is intentionally self-contained and stores completion progress only in the visitor's browser. It contains no repository credentials, private Figma links, or operational secrets.

## Files

- `index.html` · semantic page structure
- `styles.css` · responsive Pckup-themed presentation
- `data-common.js` · shared operating contract and guide metadata
- `data-phases-1.js` through `data-phases-4.js` · phase metadata and copy-ready prompts
- `app.js` · rendering, filters, copy controls, local progress, and prompt export
